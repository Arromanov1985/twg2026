TWG Lesson 03 — Voice Scripts

Содержимое:
- slide01.txt ... slide07.txt — готовые тексты для Yandex TTS;
- TWG_DF_озвучка_мастер.txt — единый сценарий для согласования.

Зафиксированное произношение:
- TWG DF -> «Ти дабл ю джи, ди эф»;
- BB20 PRO -> «Би би двадцать серии пр+о»;
- 3/4" -> «три четверти дюйма»;
- 1" -> «один дюйм»;
- 1/2" -> «полдюйма»;
- 130 мкм -> «сто тридцать микрон»;
- м³/ч -> «кубических метров в час»;
- Н·м -> «ньютон-метров».

Рекомендуемые параметры текущего голосового пайплайна:
voice=ermil
emotion=good
speed=1.0

Перед финальной упаковкой SCORM проверить произношение:
- «объёмная дисковая»;
- «гидравлическое сопротивление»;
- «глицеринозаполненный манометр»;
- «ньютон-метр»;
- «прямая промывка» — не заменять на «обратную промывку».
