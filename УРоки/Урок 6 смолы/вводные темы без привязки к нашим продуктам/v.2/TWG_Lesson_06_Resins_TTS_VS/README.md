# Урок 6 «Смолы»: генерация озвучки

Готовый проект для Visual Studio Code и PowerShell. Скрипт создаёт отдельный MP3 для каждого слайда через Yandex SpeechKit API v1.

Настройки по умолчанию:

- голос: `ermil`;
- эмоция: `good`;
- скорость: `1.0`;
- формат: MP3;
- пауза после каждой запятой: 300 мс;
- пауза между абзацами: 700 мс;
- `TWG` произносится как «ТВГ», `DF` — как «ДФ».

## Быстрый запуск в VS Code

1. Распакуйте архив и откройте папку проекта в VS Code.
2. Откройте терминал PowerShell.
3. Разрешите локальные скрипты только для текущего окна и подготовьте окружение:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup.ps1
```

4. Откройте созданный файл `.env` и вставьте ключ:

```dotenv
YANDEX_API_KEY=ваш_api_ключ
YANDEX_FOLDER_ID=идентификатор_каталога
```

Вместо API-ключа можно указать `YANDEX_IAM_TOKEN`. `YANDEX_FOLDER_ID` заполняйте, если он требуется для вашей схемы авторизации.

5. Создайте все 12 файлов:

```powershell
.\run_tts.ps1
```

Готовые файлы появятся в папке `output` с именами `slide01.mp3` — `slide12.mp3`.

## Перегенерация выбранных слайдов

Только слайд 10:

```powershell
.\run_tts.ps1 --slides 10
```

Слайды 4, 8 и с 10 по 12:

```powershell
.\run_tts.ps1 --slides "4,8,10-12"
```

Параметр `--slides 10` обрабатывает только десятый слайд и не затрагивает остальные MP3. По умолчанию выбранные файлы перезаписываются. Чтобы сохранить уже существующие MP3, добавьте `--skip-existing`.

## Проверка без расходов на API

```powershell
.\run_tts.ps1 --slides 10 --dry-run
```

## Состав проекта

- `input/slide01.txt` — `input/slide12.txt` — тексты отдельных слайдов;
- `TWG_Lesson_06_Resins_voiceover.txt` — общий текст для озвучки;
- `tts_generate.py` — основной Python-скрипт;
- `setup.ps1` — создание окружения и установка зависимостей;
- `run_tts.ps1` — запуск из PowerShell;
- `.env.example` — шаблон настроек;
- `output/` — папка готовых MP3.

На слайде 8 химические формулы переданы естественной устной формулировкой, чтобы синтезатор не зачитывал символы по буквам. Смысл исходного текста сохранён.

Официальное описание запроса API v1: https://aistudio.yandex.ru/docs/ru/speechkit/tts/request.html
