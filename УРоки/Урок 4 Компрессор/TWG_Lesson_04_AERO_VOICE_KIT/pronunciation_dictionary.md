# Словарь произношения TWG AERO 4-6

- TWG -> «Ти дабл ю джи»
- AERO 4-6 -> «Аэро четыре-шесть»
- AERO-FS -> «Аэро эф-эс»
- 1/4" -> «одна четверть дюйма»
- 5,5 атм -> «пять с половиной атмосфер»
- 6,0 атм -> «шесть атмосфер»
- 46 °C -> «сорок шесть градусов Цельсия»
- 800 000 -> «восемьсот тысяч»
- 130 °C -> «сто тридцать градусов Цельсия»

Важно: 7–8 атм и 130 °C в уроке описываются только как испытательные режимы, а не как штатные рабочие параметры.
