# Озвучка урока 4 «Компрессоры»

Пакет создаёт 20 отдельных MP3-файлов через Yandex SpeechKit:
`slide01.mp3` … `slide20.mp3`.

## Настройки по умолчанию

- язык: русский;
- голос: `ermil`;
- скорость: `1.0`;
- формат: MP3;
- исходный текст максимально сохранён;
- аббревиатура TWG передаётся в синтез как «ТВГ»;
- используется обычный текст без неподдерживаемого SSML-тега `prosody`.

## Состав

- `texts/slide01.txt` … `texts/slide20.txt` — тексты по слайдам;
- `ОБЩИЙ_ТЕКСТ_ОЗВУЧКИ.txt` — весь текст подряд;
- `timing_report.txt` — расчёт длительности;
- `synthesize_yandex.py` — генератор MP3;
- `.env.example` — шаблон настроек;
- `КОМАНДЫ_VS_CODE.txt` — команды для PowerShell в VS Code;
- `output/` — сюда сохраняется аудио.

Сначала рекомендуется сгенерировать только первый слайд и проверить голос:

```powershell
python synthesize_yandex.py --only 1 --overwrite
```

После проверки можно запустить все слайды:

```powershell
python synthesize_yandex.py --overwrite
```

Скрипт автоматически создаст в `output` архив
`TWG_AERO_4-6_AUDIO_20.zip`.
