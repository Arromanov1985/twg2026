# Voice QA — TWG Lesson 01

## До синтеза
- [x] Тексты не читают слайды дословно.
- [x] Модели приведены к дикторской форме.
- [x] Нет технических единиц в символах.
- [x] Длина каждого слайда укладывается в целевой диапазон Voice Standard.
- [x] Стиль: спокойный технический наставник.
- [x] В конце каждого экрана есть короткий вывод.

## После синтеза
- [ ] Проверить TWG: «Ти дабл ю джи».
- [ ] Проверить DF-034: «ди эф ноль тридцать четыре».
- [ ] Проверить BB20 PRO: «би би двадцать про».
- [ ] Проверить ударение «манометр», если появится в следующем уроке.
- [ ] Проверить паузы.
- [ ] Проверить отсутствие обрезанного начала/конца.
- [ ] Проверить длительность MP3.
- [ ] Проверить одинаковую громкость всех трёх файлов.
